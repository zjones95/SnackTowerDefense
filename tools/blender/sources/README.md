# Remaining tower sources

Editable, packed Blender sources for Gum, IceCreamTruck, Fondue, Gold, Boba,
and PizzaOven. Each source contains its tower studio scene. These live outside
`Assets` so Unity does not import the `.blend` files as duplicate models.

Run `tools/blender/remaining_towers.py` through Blender MCP to rebuild and export
both `Assets/Models/Towers` and `Assets/Resources/Snack/Towers`. The five new designs
are generated by the script; Gum reuses `Gum.blend`, adapted from the previously
approved generated Gumball machine. The Desktop original is only a first-run
fallback if the checked-in Gum source is absent.

The exporter preserves the editable pieces and consolidates export copies into
one multi-material head plus the shared `pedestal` and `rim`. It explicitly exports
only the active scene. The wooden base is reused from the shipped Gold GLB.
The bottom is Z=0, the base top is Z=0.18, and forward is Blender -Y.

The script also saves `Desktop/remaining_towers_gallery.blend` for reviewing all
six together. Render the gallery camera for a studio overview.

Unity verification:

```text
Unity.exe -batchmode -projectPath <project> -executeMethod RemainingTowerPreview.Render -quit -logFile <log>
```

This verifies all six models at seven scales at Y=0 and Y=-400 (84 combinations),
including base alignment, fixed bases during head rotation, and shader support.
It writes `%TEMP%/opencode/remaining_towers_unity.png`. The render uses an equal
comparison scale; gameplay still uses the normal tier scales. Actual aiming and
projectile behavior need a human play-test.
